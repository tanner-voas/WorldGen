# WorldGen v0.1.12

## Added
- Heavy static render mode available from layer 5 onward.
- Stage-aware render settings with coastline, relief, climate, hydrology, biome and vegetation emphasis where applicable.
- High-resolution export PNG from the render dialog.

## Notes
- Render is not a generation layer. It does not modify or lock the world state.
- The render dialog adapts its options to the highest completed world layer.
