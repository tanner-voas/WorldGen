# WorldGen v0.2.6 — Unified mobile header

The world title and version remain at the left of the fixed, notch-aware header. Checkpoint, 3D preview and library buttons stay in their existing order; the shared Home symbol moves to the far right when hosted by AppLauncher. When standalone, the same final button shows the shared refresh symbol and checks/installs PWA updates after a confirmed local persist. The icon animates during the update. No world data generation or storage format changes are introduced; the existing database namespace is deliberately unchanged.
